# Personal Bio Template

A beautiful, Genshin-inspired personal bio page with parchment-style design system.

## Features

- Responsive layout: Desktop sidebar + Mobile bottom navigation
- Elegant "Elemental Ledger" design with parchment textures
- Profile section with avatar and skills
- Stats grid (Projects, Years of Experience, Connections)
- Music player with play/pause controls
- Featured works/projects gallery
- Social connections section

## Quick Start

1. Clone or download this repository
2. Open `index.html` in your browser
3. Customize the placeholder content

## Customization

Replace the following placeholders in `index.html`:

| Placeholder | Description |
|-------------|-------------|
| `[YOUR_NAME]` | Your full name |
| `[YOUR_TITLE]` | Your job title or role |
| `[YOUR_BIO]` | Brief introduction about yourself |
| `[NUM]` | Statistics numbers |
| `[SONG_TITLE]` | Favorite song title |
| `[ARTIST_NAME]` | Artist name |
| `[ALBUM_NAME]` | Album name |
| `[PROJECT_NAME]` | Project/work titles |
| `[PROJECT_DESCRIPTION]` | Project descriptions |
| `[DATE]` | Project dates |

### Images

Replace placeholder images with your own:

- Avatar: Update the `src` attribute in profile section
- Album cover: Update music player background image
- Project images: Update each project card's image `src`
- Background: Change the `background-image` URL in CSS

### Social Links

Update social connection links in the `#social` section:
- Change `href="#"` to your actual profile URLs
- Add or remove social platforms as needed

## Deployment

### GitHub Pages

1. Push to GitHub repository
2. Go to Settings > Pages
3. Select source branch
4. Your site will be live at `https://username.github.io/repo-name`

### Other Options

- Netlify: Drag and drop the folder
- Vercel: Import from GitHub
- Any static hosting service

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Noto Serif + Inter)
- Material Symbols icons
- Vanilla JavaScript

## Design System

Based on "Elemental Ledger Universal" - a minimalist-tactile design with:

- Parchment base colors (#F9F7F2)
- Carbon ink text (#2C2C2C)
- Noto Serif for headings
- Inter for labels/data
- Grain overlay texture
- Frosted glass card effects
